# Інструкція для контриб'юторів

Дякуємо за бажання зробити свій внесок у розвиток проекту!

## Як запропонувати зміни:
1. Зробіть Fork цього репозиторію.
2. Створіть нову гілку: `git checkout -b feature/AmazingFeature`.
3. Зробіть комміт змін: `git commit -m 'Додано нову функцію'`.
4. Відправте зміни: `git push origin feature/AmazingFeature`.
5. Відкрийте Pull Request (PR) до основної гілки `main`.
